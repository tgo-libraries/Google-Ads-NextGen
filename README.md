# Google-Ads-NextGen

Android library for Google Mobile Ads (Next-Gen SDK): app open, banner, interstitial, native and rewarded ads.

## Install

Add JitPack to your repositories:

```gradle
maven { url "https://jitpack.io" }
```

Add the dependency:

```gradle
implementation "com.github.tgo-libraries:Google-Ads-NextGen:v1.0.0"
```
